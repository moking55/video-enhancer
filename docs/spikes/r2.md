# Spike T2: Cloudflare R2 presign / CORS

Replaces the failed RustFS attempt (`docs/spikes/rustfs.md`, kept as history).

Script: `web/scripts/storage-smoke.ts`. Run from `web/`:

```
npx -y tsx --conditions=react-server --env-file=.env.local scripts/storage-smoke.ts
```

## Setup (R2 dashboard)

- Endpoint: `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`, region `auto`, path-style (`forcePathStyle: true`).
- Bucket: `video-enhancer`.
- R2 API token: Object Read & Write, scoped to the `video-enhancer` bucket only.
- CORS (bucket settings, CORS policy):

```json
[{"AllowedOrigins":["http://localhost:3000"],"AllowedMethods":["GET","PUT","HEAD"],"AllowedHeaders":["content-type","range"],"ExposeHeaders":["ETag","Content-Length","Content-Range","Accept-Ranges"],"MaxAgeSeconds":3600}]
```

Add the Vercel origin (`https://<your-vercel-domain>`) to `AllowedOrigins` later, before deploying.
